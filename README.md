# Laboratorio - Biblioteca reserva

## Descripción 
Este repositorio contiene el desarrollo del laboratorio "Identificación e implementación de patrones de diseño en un sistema de reservas de biblioteca".

El proyecto consiste en desarrollar un prototipo de consola en Java para gestionar reservas de salas de estudio, permitiendo registrar solicitudes, verificar disponibilidad, seleccionar salas, confirmar o cancelar reservas y generar notificaciones.

El objetivo principal es comprender y aplicar los patrones de diseño Builder, Strategy, Facade, Observer y State, identificando los problemas que resuelven y cómo contribuyen a mejorar la organización y mantenibilidad del código.
